# Coin Toss Probability Simulation

## Objective

The objective of this program is to simulate repeated tosses of a **fair coin** and a **biased coin** to estimate the probability of obtaining heads. The simulation demonstrates that as the number of trials increases, the experimental probability approaches the theoretical probability, illustrating the **Law of Large Numbers**.

---

## Problem Statement

Develop a C program that simulates coin tosses for:

- A **Fair Coin** with probability of heads:
  - P(H) = 0.5
- A **Biased Coin** with probability of heads:
  - P(H) = 0.7

The program performs **100,000 trials** and records the cumulative probability of heads after every **100 tosses**. The results are stored in a CSV file for visualization and analysis.

---

## Features

- Simulates both fair and biased coin tosses.
- Uses pseudo-random number generation.
- Records cumulative probabilities after every 100 trials.
- Generates a CSV file that can be plotted in Excel, LibreOffice Calc, or Python.
- Demonstrates convergence of experimental probability to theoretical probability.

---

## Algorithm

1. Initialize the random number generator using the current system time.
2. Open a CSV file named `results.csv`.
3. Write the column headers:
   - Trials
   - Fair
   - Biased
4. Initialize counters for heads obtained from both coins.
5. Repeat for 100,000 trials:
   - Simulate a fair coin using `rand() % 2`.
   - Simulate a biased coin using a random decimal number.
   - Increment the respective head counters.
   - Every 100 trials:
     - Calculate cumulative probability.
     - Write the values to the CSV file.
6. Close the CSV file.
7. Display a success message.

## Random Number Generation

### Fair Coin

```c
rand() % 2
```

Produces:

- 0 (Tail)
- 1 (Head)

Each outcome has approximately equal probability.

---

### Biased Coin

```c
double r = (double)rand() / RAND_MAX;

if (r < 0.7)
    biasedHeads++;
```

A random number between 0 and 1 is generated.

- If `r < 0.7`, the toss is considered a Head.
- Otherwise, it is considered a Tail.

This produces approximately:

```
P(H) = 0.7
P(T) = 0.3
```
