# Tower of Hanoi – Move Count Analysis

## Objective

The objective of this program is to determine the **minimum number of moves required to solve the Tower of Hanoi problem** using recursion. The program calculates the number of moves for different numbers of disks (1 to 20) and stores the results in a CSV file for graphical analysis and verification of the recursive algorithm.

---

## Problem Statement

Implement a recursive solution to solve the **Tower of Hanoi** problem. Instead of printing every move, the program counts the total number of moves required to transfer all disks from the source rod to the destination rod while following the Tower of Hanoi rules.

The program computes the number of moves for **1 to 20 disks** and stores the results in a CSV file.

---

## Tower of Hanoi Rules

The puzzle consists of three rods:

- Source Rod (A)
- Auxiliary Rod (B)
- Destination Rod (C)

The following rules must always be followed:

1. Only one disk can be moved at a time.
2. Only the top disk of a rod can be moved.
3. A larger disk can never be placed on a smaller disk.

---

## Features

- Recursive implementation of the Tower of Hanoi algorithm.
- Counts the total number of moves without printing each move.
- Generates a CSV file containing the number of disks and corresponding moves.
- Demonstrates exponential growth of the recursive solution.
- Suitable for plotting graphs and analyzing time complexity.

---

## Algorithm

1. Open the file `moves.csv` in write mode.
2. Write the CSV header (`Disks, Moves`).
3. For each number of disks from **1 to 20**:
   - Reset the move counter.
   - Call the recursive Tower of Hanoi function.
   - Count every valid disk movement.
   - Store the result in the CSV file.
   - Display the number of moves on the console.
4. Close the CSV file.
5. Display a success message.

---

## Recursive Logic

For **n** disks:

1. Move **n − 1** disks from the source rod to the auxiliary rod.
2. Move the largest disk to the destination rod.
3. Move the **n − 1** disks from the auxiliary rod to the destination rod.

The recursive relation is:

```
T(n) = 2T(n − 1) + 1
```

with the base case:

```
T(1) = 1
```

The closed-form solution is:

```
T(n) = 2ⁿ − 1
```

## Observations

- The number of moves doubles and increases by one for each additional disk.
- The move count follows the mathematical expression:

```
Moves = 2ⁿ − 1
```

- The growth is exponential.
- Even a small increase in the number of disks results in a significant increase in the required moves.
- For 20 disks, the puzzle requires **1,048,575** moves.

---

## Time Complexity

The recurrence relation is:

```
T(n) = 2T(n − 1) + 1
```

Therefore,

```
Time Complexity = O(2ⁿ)
```

The recursive function performs one operation for every move.

---

## Space Complexity

The recursive calls create a call stack whose maximum depth equals the number of disks.

```
Space Complexity = O(n)
```
