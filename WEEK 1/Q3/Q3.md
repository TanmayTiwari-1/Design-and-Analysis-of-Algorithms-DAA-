# Bubble Sort Performance Comparison

## Objective

The objective of this experiment is to compare the performance of **Optimized Bubble Sort** and **Unoptimized Bubble Sort** by counting the number of comparisons performed for different input sizes. The experiment demonstrates how the optimization of terminating early when no swaps occur improves Bubble Sort's efficiency for already sorted arrays while having little effect on random arrays.

---

## Problem Statement

Implement two versions of the Bubble Sort algorithm:

1. **Optimized Bubble Sort**
   - Stops execution if no swaps occur during a pass.
   - Best suited for already sorted or nearly sorted arrays.

2. **Unoptimized Bubble Sort**
   - Executes all passes regardless of whether the array is sorted.

Compare the number of comparisons performed by both algorithms on:

- Randomly generated arrays
- Already sorted arrays

Store the results in CSV files for plotting graphs and analyzing algorithm performance.

---

## Features

- Implements both optimized and unoptimized Bubble Sort.
- Generates random arrays of different sizes.
- Tests both algorithms using identical input arrays.
- Measures the number of element comparisons.
- Performs an additional experiment using already sorted arrays.
- Stores results in CSV files for visualization.
- Prints comparison tables on the console.

---

## Algorithm

### Part A – Random Input

1. Initialize the random number generator.
2. Create arrays of different sizes.
3. Fill the base array with random integers.
4. Copy the base array into two separate arrays.
5. Sort one array using Optimized Bubble Sort.
6. Sort the other using Unoptimized Bubble Sort.
7. Count the number of comparisons performed.
8. Store the results in `bubble_sort_data.csv`.

---

### Part B – Already Sorted Input

1. Create already sorted arrays.
2. Apply Optimized Bubble Sort.
3. Apply Unoptimized Bubble Sort.
4. Count the comparisons.
5. Store the results in `bubble_sort_sorted_data.csv`.

## Observations

### Random Arrays

- The optimized and unoptimized Bubble Sort algorithms perform nearly the same number of comparisons.
- Since random arrays require swaps in almost every pass, the optimized version rarely exits early.
- Consequently, both algorithms exhibit approximately **O(n²)** time complexity.

---

### Already Sorted Arrays

- The optimized Bubble Sort performs only **n − 1** comparisons.
- Since no swaps occur during the first pass, the algorithm terminates immediately.
- The unoptimized Bubble Sort continues executing all passes despite the array already being sorted.
- This demonstrates the effectiveness of the early-exit optimization.

---

## Result Analysis

| Input Type | Optimized Bubble Sort | Unoptimized Bubble Sort |
|-------------|----------------------|--------------------------|
| Random Array | O(n²) | O(n²) |
| Already Sorted Array | O(n) | O(n²) |

The experimental results closely match the theoretical time complexities.

## Conclusion

The experiment verifies that the optimization of terminating Bubble Sort when no swaps occur significantly improves its performance for already sorted or nearly sorted arrays, reducing the best-case time complexity from **O(n²)** to **O(n)**. However, for randomly ordered arrays, both optimized and unoptimized versions perform almost the same number of comparisons, maintaining an average-case complexity of **O(n²)**.
