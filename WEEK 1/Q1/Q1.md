# Growth Functions Analysis

## Objective

This program evaluates and compares the growth of various mathematical functions commonly used in the analysis of algorithms. The generated data can be used to study asymptotic growth and visualize the differences between functions using graphs.

---

## Functions Evaluated

The program computes the following functions for values of **n** ranging from **2 to 1024** (powers of 2):

1. 1/n
2. log₂(n)
3. 12√n
4. 50√n
5. n^0.51
6. 2³² × n
7. n log₂(n)
8. 100n² + 6n
9. n² − 324
10. 2n³
11. n^(log₂n)
12. 3ⁿ

---

## Algorithm

1. Open a CSV file named `growth.csv` in write mode.
2. Write the column headers.
3. Initialize `n = 2`.
4. Repeat until `n = 1024`:
   - Compute the value of each function.
   - Store the values in the CSV file.
   - Double the value of `n`.
5. Close the file.
6. Display a success message.

---

## Input

No user input is required.

---

## Output

A CSV file named **growth.csv** containing the calculated values of all growth functions.

Example:

| n | 1/n | log₂(n) | 12√n | ... |
|---|------|----------|-------|-----|
| 2 | 0.5 | 1 | 16.97 | ... |
| 4 | 0.25 | 2 | 24 | ... |
| 8 | 0.125 | 3 | 33.94 | ... |

## Requirements

- C Compiler (GCC recommended)
- Standard C Libraries:
  - stdio.h
  - math.h

---

## Compilation

Using GCC:

```bash
gcc growth.c -o growth -lm
```

The `-lm` flag links the math library.

---

## Execution

Run the program:

```bash
./growth
```

On Windows:

```bash
growth.exe
```

After execution, the file `growth.csv` will be created in the current directory.

---

## Time Complexity

The loop executes once for every power of two from 2 to 1024.

Number of iterations:

```
log₂(1024) = 10
```

Therefore,

**Time Complexity:** O(log n)

---

## Space Complexity

The program uses only a fixed number of variables regardless of input size.

**Space Complexity:** O(1)
