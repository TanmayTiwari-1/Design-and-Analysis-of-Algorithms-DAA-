# DAA Lab-08 - Dynamic Programming (Solutions in C)

One folder per question: `.c` source, `input.txt`, `output.txt` (real output), `README.md` (idea, recurrence, complexity).
Q9 also has graphs and a small Python plot script.

| Q | Problem | Time | Space |
|---|---|---|---|
| 1 | Minimum coin change | O(nV) | O(V) |
| 2 | Coin change - number of ways | O(nV) | O(V) |
| 3 | LCS + reconstruction | O(mn) | O(mn) |
| 4 | Longest increasing subsequence | O(n^2) | O(n) |
| 5 | Max sum increasing subsequence | O(n^2) | O(n) |
| 6 | Edit distance + traceback | O(mn) | O(mn) |
| 7 | Rod cutting + reconstruction | O(n^2) | O(n) |
| 8 | Optimal BST | O(n^3) | O(n^2) |
| 9 | Collatz analyser | no proven bound | O(b-a+1) |

Every program reads from **stdin**. Build and run everything with `bash run_all.sh` (needs gcc).
